# 公司附近午餐美食圖（PWA）

同事登入後，在地圖上查看公司附近的午餐店、新增店家、評分與留短評（示範，資料全為虛構）。需求見 `需求筆記.txt`，專案規則見 `AGENTS.md`。

## 檔案

- `index.html`、`style.css`、`app.js`、`config.js`：網頁（登入、暱稱、地圖／清單、篩選、新增店家、評分）
- `manifest.webmanifest`、`sw.js`、`pwa.js`、`icons/`：PWA 設定（可安裝到手機主畫面）
- `supabase/schema.sql`：Supabase 建表 SQL（暱稱、店家、評價與存取規則）
- `美食圖欄位表.xlsx`：欄位表與範例資料（虛構）

## 設定（負責人只需做一次）

1. 在 Supabase 的 SQL Editor 執行 `supabase/schema.sql`。
2. 在 Supabase 的 Authentication：
   - **關閉自行註冊**（Allow new users to sign up），否則任何人都能註冊後看到資料。
   - 在 Users 為每位同事建立帳號（Email＋密碼），再把帳號密碼私下交給同事。
3. `config.js` 只能放 publishable key；secret key、帳號 Email 與密碼不可以寫進任何檔案。

## 使用方式

- **第一次登入**：設定暱稱（1～20 字，不能用 Email）。評價和新增的店家只會顯示暱稱。按右上角暱稱可以修改。
- **地圖／清單**：地圖標記上的數字是平均分數。綠色＝4 分以上、橘色＝3 分以上、紅色＝3 分以下、灰色＝尚無評分。**點標記直接進入店家頁面**（評分、評價、導航、Google 地圖）。
- **Google 地圖 ↗**：在店家頁面開啟 Google 地圖上那家店的頁面（照片、評論、營業時間）。用店名＋地址搜尋，地址填得完整比較準。
- **篩選**：料理類型、價位、步行時間、可外送、我還沒評過；排序可選評分、步行距離、最新加入。
- **評分**：點店家的「評分」，選星星並可留短評。每家店每人只能評一次，送出後不能修改（需要更正請找管理者）。
- **新增店家**：按右下角「＋」，用搜尋找店名或地址，或直接點地圖放位置，再填店名、料理類型等資料。新增後不能自行修改或刪除。
- **管理者**：在 Supabase 後台的 Table Editor 刪除不適合或重複的店家與評價（刪除店家會一併刪除它的評價）。

## 安裝成 App

- Android（Chrome）：開啟網址後按右上角「安裝 App」，或從瀏覽器選單選「安裝應用程式」。
- iPhone（Safari）：開啟網址 → 分享按鈕 →「加入主畫面」。
- 離線時可以開啟畫面，但資料需要連網才能讀取。

## 圖示與背景
