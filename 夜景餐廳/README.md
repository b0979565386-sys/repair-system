# 夜景餐廳口袋名單（PWA）

臺灣夜景餐廳清單（示範，資料全為虛構）。不用登入，打開就能用。只收臺灣（含澎湖、金門、馬祖）的餐廳。

> **注意：** 不用登入代表任何拿到網址的人都能看到、修改、刪除整份清單。請只放可以公開的內容。需求見 `需求筆記.txt`，專案規則見 `AGENTS.md`。

## 檔案

- `index.html`、`style.css`、`app.js`、`config.js`：網頁（搜尋景點、新增、修改、刪除、篩選）
- `manifest.webmanifest`、`sw.js`、`icons/`：PWA 設定、Service Worker 與 App 圖示
- `supabase/schema.sql`：Supabase 建表 SQL 與照片儲存桶（不用登入，任何人可讀寫）

## 設定（只需做一次）

1. 在 Supabase 的 SQL Editor 執行 `supabase/schema.sql`。
   - 如果之前執行過需要登入的舊版，直接再執行一次新版即可：會移除舊的擁有者欄位與政策，既有的餐廳資料會保留。
2. `config.js` 只能放 publishable key；secret key 不可以寫進任何檔案。
3. 需要備份時，在 Supabase 的 Table Editor 打開 `night_view_restaurants`，用 Export 匯出 CSV。

## 只限臺灣

- 縣市是下拉選單，只能選臺灣 22 個縣市；「台北市」這類寫法會自動改成正式的「臺北市」。
- 搜尋景點只會找臺灣的地點，並自動帶入縣市。
- 地圖只能在臺灣附近移動，表單的地圖只能點選臺灣範圍內的位置。
- 升級：再執行一次 `supabase/schema.sql`。舊資料不會被刪除或拒絕，但修改不是臺灣縣市或位置在國外的舊資料時，要先改成臺灣的縣市、重新點選位置（或清除位置）才能儲存。

## 搜尋景點

畫面上方的「搜尋景點」可以直接查詢真實地點（例如「象山」「台北 高空餐廳」）：

1. 輸入名稱後按「搜尋」，最多列出 8 個結果。
2. 按「在地圖查看 ↗」可以在地圖 App 開啟位置。
3. 按「加入清單」會開啟新增表單，自動帶入名稱、城市、地址與網址（有的話），補上夜景類型後儲存。

搜尋使用 OpenStreetMap 的 Nominatim 服務，不需要金鑰；輸入的關鍵字會送到 OpenStreetMap 的伺服器。找不到時試著加上城市名稱。

## 匯出

- 「我的清單」右邊的「匯出」可以選範圍（目前篩選結果或全部）與格式：
  - **CSV**：可用 Excel、Google 試算表開啟，欄位名稱是中文。
  - **JSON**：完整備份，包含所有欄位與照片網址。
- 檔名為 `night-view_日期_時間.csv`／`.json`。照片只匯出網址，不包含圖片檔。
- 在 iPhone 上會開啟預覽，按分享按鈕可以存到「檔案」或傳給別人。

## 照片

- 新增或修改時，在「照片」區塊按「＋ 加入照片」，可以拍照或從相簿選（一次可選多張），每家最多 6 張；按照片右上角的「×」可以移除。
- 上傳前會自動縮小（長邊 1600 像素）並重新存成 JPEG，同時移除照片裡的定位資訊。
- 清單卡片與地圖彈出視窗會顯示第一張照片，點了可以全螢幕左右滑動看全部。
- 照片存在 Supabase Storage 的公開儲存桶 `night-view-photos`，和清單一樣，任何拿到網址的人都看得到、也能刪除。

升級：再執行一次 `supabase/schema.sql` 就會建立照片欄位與儲存桶，既有資料不受影響。

## 地圖

- 篩選列下方可以切換「清單」與「地圖」。地圖顯示有位置的餐廳：黃色＝想去、綠色＝去過；點標記可以「導航 ↗」或「修改」。
- 清單卡片上的「地圖」按鈕會直接在地圖上找到那家餐廳。
- 設定位置：用「搜尋景點」加入會自動帶入位置；也可以在新增／修改表單的「位置（地圖）」點一下地圖，再點別處可以移動，按「清除位置」可以移除。
- 「📍 我的位置」會詢問定位權限，只用來移動地圖，不會儲存。
- 地圖使用 Leaflet 與 OpenStreetMap 圖磚，不需要金鑰；離線時地圖不會顯示，清單仍可開啟畫面。

升級：已經執行過舊版 SQL 的話，再執行一次 `supabase/schema.sql` 即可加上緯度、經度欄位，既有資料不受影響。

## 圖示與背景

App 圖示與頁面背景使用 `images/background.jpg`（湖面熱氣球，需求方提供）。圖示是從這張圖裁切的；原圖 500×500 像素，在大螢幕上當背景會稍微模糊。

## 安裝到手機

- Android（Chrome）：開啟網址 → 右上角選單 →「安裝應用程式」，或按畫面上的「安裝 App」。
- iPhone（Safari）：開啟網址 → 分享按鈕 →「加入主畫面」。

離線時可以開啟 App 畫面，但清單需要連網才能讀取與修改。

## 本機預覽

在儲存庫根目錄執行：

```bash
python3 -m http.server 8000
```

再開啟 http://localhost:8000/夜景餐廳/ 。
